# Luxe Drive - Sistem Rental Mobil

Aplikasi web rental mobil premium berbasis PHP Native + MySQL.

## Cara Menjalankan
1. Clone repo ke folder htdocs (XAMPP)
2. Buat database luxe_drive di phpMyAdmin
3. Import database/luxe_drive.sql
4. Buka http://localhost/luxe-drive/beranda.php
